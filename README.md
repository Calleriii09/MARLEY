# ECLIPSE: Legends Awakened — versão 0.3.0

RPG Idle de navegador com direção artística híbrida: fantasia sombria + anime.

## Novidades desta versão
- Barra de vitalidade da equipe durante as batalhas.
- Ataques inimigos agora reduzem a vitalidade; a defesa diminui o dano recebido.
- Derrota permite tentar a mesma fase novamente sem perder o progresso.
- Ajuste no cálculo das recompensas offline para não repetir o mesmo período ao reabrir o jogo.
- Mantém heróis ilustrados, cartas, fusão, treinamento, equipamentos, chefes, fases e salvamento local.

## Como jogar no Android
Para evitar bloqueios ao abrir arquivos locais, recomendamos publicar no GitHub Pages: crie um repositório público, envie o conteúdo desta pasta para a raiz (o `index.html` deve ficar na raiz), depois abra Settings > Pages e escolha Deploy from a branch, `main` e `/(root)`. Use o endereço publicado no Chrome.

## Salvamento
O progresso fica no armazenamento local do navegador e dispositivo. Não limpe os dados do site para evitar perder seu progresso. O salvamento não sincroniza entre aparelhos.

Versão incremental de desenvolvimento. As artes são ilustrações vetoriais originais em estilo pixel-inspired, ainda sem spritesheets animados quadro a quadro.
